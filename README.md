# Uptime Sentinel

Uptime Sentinel monitors websites on a schedule, records response history, and alerts you when availability changes.

## Requirements

- Node.js 20.19 or newer
- MySQL 8 or newer, local or hosted
- SMTP credentials for email alerts

## Features

- JWT authentication with bcrypt-hashed passwords
- MySQL persistence through Sequelize
- Site creation, editing, pause/resume, and deletion
- Scheduled availability checks
- Public status pages
